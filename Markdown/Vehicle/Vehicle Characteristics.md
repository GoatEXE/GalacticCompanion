# Definitions
- <b>Handling</b>: Number of boost or setback added to the pool when making Piloting checks. ([p. 236](https://online.anyflip.com/ziisf/jobq/mobile/index.html#p=236))
- <b>Speed</b>: An abstract maximum speed value for this vehicle. ([p. 237](https://online.anyflip.com/ziisf/jobq/mobile/index.html#p=237))
- <b>Silhouette</b>: An abstract value respresenting size between 0 to 10+, 0 being sub-human. If attacker and target differ by 2 or more silhouette, the larger target is easier to hit by 1 difficulty step and the smaller target is harder to hit by 1 difficulty step. ([pp. 236-238](https://online.anyflip.com/ziisf/jobq/mobile/index.html#p=236))
- <b>Defense</b>: Defense adds setback to incoming attacks; it can come from shields, evasive systems, or similar defenses. ([p. 248](https://online.anyflip.com/ziisf/jobq/mobile/index.html#p=248))
- <b>Defense Zones</b>: Some vehicles divide defense by facing or zone; exact zone layout and redistribution depend on the chassis and vehicle rules. ([p. 248](https://online.anyflip.com/ziisf/jobq/mobile/index.html#p=248))
- <b>Armor</b>: This soak value reduces incoming damage by that amount. ([p. 237](https://online.anyflip.com/ziisf/jobq/mobile/index.html#p=237))
- <b>Hull Trauma Threshold</b>: A number of hit points before structural failure. ([p. 237](https://online.anyflip.com/ziisf/jobq/mobile/index.html#p=237))
- <b>System Strain Threshold</b>: A vehicle's stress limit; if strain exceeds it, the vehicle's systems begin overloading and shutting down until repaired or rebooted. System strain can be recovered through Damage Control or by spending a full day without taking more system strain. ([p. 238](https://online.anyflip.com/ziisf/jobq/mobile/index.html#p=238))
- <b>Hard Points</b>: A number of customizations supported by the vehicle chassis. ([p. 237](https://online.anyflip.com/ziisf/jobq/mobile/index.html#p=237))
