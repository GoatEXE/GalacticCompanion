# Definitions
- <b>Handling</b>: Number of boost or setback added to the pool when making Piloting checks. ([p. 236](https://online.anyflip.com/ziisf/jobq/mobile/index.html#page=237))
- <b>Speed</b>: An abstract maximum speed value for this vehicle. ([p. 237](https://online.anyflip.com/ziisf/jobq/mobile/index.html#page=238))
- <b>Silhouette</b>: An abstract value representing size between 0 to 10+, 0 being sub-human. Vehicle combat compares the firing vessel's silhouette to the target's silhouette for attack difficulty. ([pp. 236-238](https://online.anyflip.com/ziisf/jobq/mobile/index.html#page=237), [p. 249](https://online.anyflip.com/ziisf/jobq/mobile/index.html#page=250))
- <b>Defense</b>: Defense represents shields, point defense, speed, or similar protection; each point adds one setback to incoming attacks. ([p. 238](https://online.anyflip.com/ziisf/jobq/mobile/index.html#page=239))
- <b>Defense Zones</b>: Some vehicles divide defense by facing or zone; exact zone layout and redistribution depend on the chassis and vehicle rules. ([p. 238](https://online.anyflip.com/ziisf/jobq/mobile/index.html#page=239))
- <b>Armor</b>: This soak value reduces incoming damage by that amount. ([p. 237](https://online.anyflip.com/ziisf/jobq/mobile/index.html#page=238))
- <b>Hull Trauma Threshold</b>: A number of hit points before structural failure. ([p. 237](https://online.anyflip.com/ziisf/jobq/mobile/index.html#page=238))
- <b>System Strain Threshold</b>: A vehicle's stress limit; if strain exceeds it, the vehicle's systems begin overloading and shutting down until repaired or rebooted. System strain can be recovered through Damage Control or by spending a full day without taking more system strain. ([p. 238](https://online.anyflip.com/ziisf/jobq/mobile/index.html#page=239))
- <b>Hard Points</b>: A number of customizations supported by the vehicle chassis. ([p. 237](https://online.anyflip.com/ziisf/jobq/mobile/index.html#page=238))

# Standard Ship Systems
- <b>Sublight Engines</b>: Provide realspace propulsion for atmospheric and intrasystem travel. ([p. 239](https://online.anyflip.com/ziisf/jobq/mobile/index.html#page=240))
- <b>Hyperdrive</b>: Enables hyperspace travel; a lower class rating is faster, while backup drives are usually slower. ([p. 239](https://online.anyflip.com/ziisf/jobq/mobile/index.html#page=240))
- <b>Navicomputer</b>: Calculates safe hyperspace routes, either as a dedicated computer or with astromech support. ([p. 239](https://online.anyflip.com/ziisf/jobq/mobile/index.html#page=240))
- <b>Escape Pods/Ejection Systems</b>: Support emergency evacuation and short-term survival after abandoning the craft. ([p. 239](https://online.anyflip.com/ziisf/jobq/mobile/index.html#page=240))
- <b>Sensors</b>: Passively cover 360 degrees to their listed range; active mode reaches one band farther in one arc but requires an Easy Computers check. ([p. 239](https://online.anyflip.com/ziisf/jobq/mobile/index.html#page=240))
- <b>Comms</b>: Normally reach as far as the sensors, though standard signals can be intercepted or jammed. ([p. 239](https://online.anyflip.com/ziisf/jobq/mobile/index.html#page=240))
- <b>Transponder</b>: Broadcasts registry and identity data, can act as a distress beacon, and may attract legal scrutiny if tampered with. ([p. 239](https://online.anyflip.com/ziisf/jobq/mobile/index.html#page=240))
