# Face Values
- Success (💥) countered by Failure (🔻) ([p. 30](https://online.anyflip.com/ziisf/jobq/mobile/index.html#page=31))
- Advantage (🐦‍🔥) countered by Threat (⚛️). Can be spent to restore strain, perform extra maneuver, or activate a weapon effect. ([p. 30](https://online.anyflip.com/ziisf/jobq/mobile/index.html#page=31))
- Despair (⭕🔻) and Triumph (⚔️) can be countered by success and failure, but their special effects always cumulatively apply. ([pp. 217-218](https://online.anyflip.com/ziisf/jobq/mobile/index.html#page=218))
- Light Side (⚪) destiny points and Dark Side (⚫) destiny points can be found on the white d12. See more under "Destiny Points" section.

# Building Dice Pool
- Find the skill and parent trait value. The number of ability dice (d8) rolled are equal to the higher of the two values. ([p. 26](https://online.anyflip.com/ziisf/jobq/mobile/index.html#page=27))
- Upgrade those dice from d8 to proficiency dice (d12) equal to the value of the lower number. 
- If upgrades exceed the dice currently in the pool, add one base die of the appropriate type, then upgrade it if upgrades remain. Repeat as needed. ([p. 28](https://online.anyflip.com/ziisf/jobq/mobile/index.html#page=29))
- Add dice as needed (boost, destiny, equipment)
- GM selects number of difficulty dice (0 = simple, 1 = easy, 2 = average etc.) ([p. 25](https://online.anyflip.com/ziisf/jobq/mobile/index.html#page=26))
- Address wounds from crits/environment as necessary for setback dice (d6) ([pp. 27-28](https://online.anyflip.com/ziisf/jobq/mobile/index.html#page=28))
- GM can upgrade difficulty to challenge dice (d12) via destiny points.
- Downgrade where applicable by converting upgraded dice back to their base type where possible. Extra downgrades are ignored if no upgraded dice remain. ([p. 29](https://online.anyflip.com/ziisf/jobq/mobile/index.html#page=30))
- Remove dice where applicable only after add, upgrade, and downgrade steps are complete. ([p. 29](https://online.anyflip.com/ziisf/jobq/mobile/index.html#page=30))
